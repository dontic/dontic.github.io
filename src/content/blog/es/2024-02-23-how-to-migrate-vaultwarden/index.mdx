## Contexto

Hace poco creé una nueva instancia de Vaultwarden en mi homelab y quería migrar mi vault antiguo a la nueva instancia.

Sí, se puede exportar el vault desde la interfaz, pero yo tenía varios familiares como usuarios y no tenía acceso a sus cuentas, así que necesitaba otra forma de migrar todo a la nueva instancia.

Para dar contexto, ejecuto Vaultwarden en un LXC de Ubuntu en mi servidor Proxmox. Usé [Proxmox Community Scripts](https://community-scripts.org/scripts/vaultwarden) para instalarlo.

## Así puedes migrar tus datos de Vaultwarden

### 1. Haz una copia de seguridad de los datos originales

1. Conéctate por SSH a donde tengas instalado Vaultwarden

2. Localiza el directorio `data`.
   Dependiendo de tu versión de Vaultwarden, la carpeta `data` puede estar en:
   - `/opt/vaultwarden/data`
   - `/var/lib/vaultwarden/data`

3. Comprime el directorio `data` con:

```bash
tar -czvf vaultwarden_data.tar.gz /opt/vaultwarden/data
```

4. Copia el archivo comprimido a un lugar seguro. Yo simplemente lo transferí a mi máquina local vía SFTP.

### 2. Migra los datos a una nueva instancia de Vaultwarden

1. Instala la nueva instancia de Vaultwarden
2. Detén Vaultwarden

```bash
systemctl stop vaultwarden
```

3. Elimina el directorio de datos por defecto

```bash
sudo rm -r /opt/vaultwarden/data
```

4. Copia el archivo de datos comprimido a la nueva instancia (yo usé SFTP, pero puedes usar cualquier sistema de transferencia de archivos que prefieras).

5. Descomprime los datos:

```bash
tar -xzvf vaultwarden_data.tar.gz -C /
```

5. Elimina las claves RSA antiguas del directorio `data`. Estas se volverán a generar

```bash
sudo rm /opt/vaultwarden/data/rsa_key.pem
```

```bash
sudo rm /opt/vaultwarden/data/rsa_key.pub.pem
```

6. Cambia el propietario del directorio a vaultwarden

```bash
sudo chown -R vaultwarden:vaultwarden /opt/vaultwarden/data
```

7. Reinicia Vaultwarden

```bash
sudo systemctl start vaultwarden
```

¡Listo!

Ahora deberías poder acceder a Vaultwarden en el endpoint que hayas configurado y tener disponible todo tu vault antiguo.
